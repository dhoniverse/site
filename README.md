# Dhoniverse Festival Website

A beautiful, fully responsive website for Dhoniverse - a three-day cultural and adventure festival in Dhoni village, Palakkad, Kerala.

## 🌿 About

Dhoniverse celebrates the rich cultural heritage and natural beauty of Dhoni village through a blend of traditional performances, adventure sports, and community activities. This website captures the essence of the festival with a nature-inspired design and intuitive user experience.

## ✨ Features

### Design
- **Nature-Inspired Theme**: Earthy color palette featuring greens, browns, and warm sunset tones
- **Custom Typography Logo**: Dhoniverse branding with professional logo design
- **Clean Typography**: Lexend Deca font for excellent readability across all devices
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Modern Animations**: Smooth scroll effects, fade-in animations, and interactive elements
- **Accessibility**: Keyboard navigation support and ARIA-compliant elements

### Sections
1. **Hero Section**: Eye-catching introduction with the festival tagline
2. **About**: Overview of Dhoniverse and Dhoni village
3. **Event Highlights**: Showcase of 9 major events including:
   - Theyyam Performance
   - Kalaripayattu
   - Cycle Races
   - Dirt Bike Challenge
   - Kolam Varakkal
   - Kabbaddi
   - Gatta Gusthi
   - Mentalism
   - Kaala Performance
4. **Schedule**: Detailed 3-day festival timeline
5. **Gallery**: Photo grid with 27+ images showcasing village life and festival moments
6. **Contact**: Contact form and location information

### Technical Features
- Lazy loading images for optimal performance
- Smooth scrolling navigation
- Mobile-friendly hamburger menu
- Scroll-to-top button
- Image modal for gallery viewing
- Form validation
- Notification system
- Parallax effects

## 🚀 Getting Started

### Simple Setup
1. **Save your logo**: Save your Dhoniverse logo as `dhoniverse-logo.png` in the main directory
2. Ensure all files are in the same directory:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `dhoniverse-logo.png` (your typography logo)
   - `images/` folder with all festival images

3. Open `index.html` in any modern web browser

### Recommended Browsers
- Google Chrome (latest)
- Mozilla Firefox (latest)
- Microsoft Edge (latest)
- Safari (latest)
